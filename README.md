# Bobaloka Acessórios

Site institucional da Bobaloka Acessórios, com os principais links da marca: WhatsApp, grupo VIP, localização, catálogos, linhas e redes sociais.

## Como ver

Abra `index.html` no navegador ou sirva a pasta localmente:

```bash
python3 -m http.server 8765
```

Depois acesse [http://127.0.0.1:8765/](http://127.0.0.1:8765/).

## Estrutura

```
index.html          Página principal
css/styles.css      Layout e identidade visual
js/main.js          Fallback de imagens
assets/images/      Logo, foto da loja e linhas
assets/icons/       Ícones SVG
```
